# Frada Joinville - Form ONG

Projeto escolar e conceitual desenvolvido para fins de apresentacao e estudo, simulando uma plataforma web institucional para a ONG Frada Joinville (Frente de Acao pelos Direitos Animais).

## Sobre o Projeto

Este projeto tem carater estritamente academico/educacional. Ele foi elaborado como um conceito de aplicacao web para demonstrar a estrutura de divulgacao de animais para adocao, paginas informativas de apoio e um formulario interativo de adocao com validacoes no lado do cliente.

Todas as informacoes e fluxos apresentados sao demonstrativos e destinados a avaliacao escolar.

## Funcionalidades

- Catalogo de Animais: Exibicao conceitual de cards com fotos e perfis de animais para adocao.
- Formulario de Adocao: Coleta simulada de dados com validacoes em JavaScript (verificacao de CPF, campos condicionais de moradia e controle de horas).
- Paginas Informativas: Sessoes conceituais sobre como ajudar a ONG, orientacoes sobre lar temporario e guia de procedimentos em caso de resgates.
- Menu Responsivo: Navegacao funcional adaptada para diferentes tamanhos de tela.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Estrutura do Projeto

```text
form-ong/
├── assets/             # Imagens, icones e recursos visuais
├── ajude.html          # Pagina conceitual sobre formas de ajuda
├── form.html           # Formulario de adocao com validacao
├── index.html          # Pagina inicial com cards dos animais
├── oquefazer.html      # Guia informativo de procedimentos
├── script.js           # Scripts de validacao e comportamento do menu
├── style.css           # Estilizacao e layout
└── temporario.html     # Pagina sobre acolhimento temporario
```

## Como Executar

1. Clone este repositorio:
   ```bash
   git clone https://github.com/isabela728/form-ong.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd form-ong
   ```

3. Abra o arquivo `index.html` em qualquer navegador web ou utilize a extensao Live Server no Visual Studio Code.
